## 📖 소개
기술 블로그의 새 글을, 관심 있는 키워드, 토픽만 구독해두면 매일 수집, 분류해서 관심사에 맞는 글만 메일로 보내주는 서비스입니다.
학습 노트를 남기면 관린 글을 추천하고, 관련 키워드 사이의 관계를 시각화합니다.

<br/>

## ✨ 주요 기능

| | 기능 | 설명 |
| :---: | --- | --- |
| 🔖 | **키워드, 토픽 구독 알림** | 관심 키워드/토픽을 담아두면 그 주제의 새 글만 골라 모아줍니다. |
| 📰 | **매일 자동 수집, 분류** | 기술 블로그 RSS를 수집하고 AI로 글의 핵심 키워드를 분류합니다. |
| 📝 | **노트 기반 글 추천** | 학습 노트를 쓰면 키워드를 추출해 관련 있는 글을 추천합니다. |
| 🕸️ | **키워드 지식 그래프** | 함께 등장한 키워드의 관계를 그래프로 시각화해 탐색합니다. |
