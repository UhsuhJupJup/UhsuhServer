# ADR-0004: 아웃박스 행에 렌더링된 이메일을 통째로 저장(fat row)

## Status

Accepted (2026-08-27)

## Context

- 아웃박스 행(ADR-0003)에 **무엇을 저장할지** 정해야 했다.
- 참조(memberId, articleIds)만 저장하면 폴러가 발송 시점에 다시 렌더링해야 하는데, 그사이 원본 글이 수정·삭제되면 재시도마다 다른 메일이 나갈 수 있고, 폴러가 도메인(글·키워드·렌더러)에 의존하게 된다.

## Decision

`recipient`, `subject`, `body`(렌더된 HTML, MEDIUMTEXT), `unsubscribe_url` 등 **완성된 발송 페이로드를 통째로** 저장한다. `recipient`는 FK가 아니라 이메일 **문자열**로 둔다(발송 큐는 도메인 관계가 아니라 목적지의 스냅샷).

## Alternatives

- 참조/이벤트만 저장(발송 시 재렌더링): 저장은 가볍지만 결정 시점을 동결하지 못하고 폴러가 도메인에 결합된다.
- `recipient`를 member/subscriber FK로: 발송 전에 이메일 변경·탈퇴 시 깨지거나 엉뚱한 곳으로 발송될 수 있다.

## Consequences

- (+) **결정 시점 동결** — 08:00에 정한 그대로 나간다. 재시도가 **같은 바이트**를 보내 예측 가능(멱등적 재시도). 폴러가 도메인 비의존("바보 폴러").
- (-) 본문이 수신자마다 중복 저장되어 **저장소가 팽창**한다. `recipient_type`, `article_count` 등 발송 로그용 부가 컬럼이 붙는다.
- (=) 참조무결성·조인을 포기한다. `SENT` 미퍼지 시 무한 성장(→ ADR-0008과 동일 부채).
- 재검토: 저장량이 문제되면 참조형 전환 또는 본문 외부 저장.
